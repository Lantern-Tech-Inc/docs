Set up a brand, understand its current AI-search position, and start useful work.

## 1. Create your workspace

Choose whether you are setting up Lantern for your own organization or for agency clients. Add your profile details and primary brand website.

Lantern researches the website to prepare initial brand context, topics, competitors, and suggested prompts. Review this information before relying on it.

## 2. Review Brand Kit

Confirm the brand name, website, description, positioning, audience, voice, competitors, and topics. Add supporting knowledge sources when the default website context is not enough.

## 3. Connect data

Connect the sources relevant to your work:

- Google Search Console for queries, impressions, clicks, CTR, and positions.
- Google Analytics for sessions, pages, acquisition, and AI referrals.
- A supported CMS for content drafts and publishing workflows.
- Slack for selected workflow and approval notifications.

## 4. Establish an AI visibility baseline

Open Analytics and review the tracked prompt set. Run or schedule visibility analysis only after the prompt set represents real buyer questions for the brand.

## 5. Ask LanternIQ for the next action

Try this request:

```text
Review the latest visibility, citation, search, and brand evidence. What should we prioritize this week, and why?
```

Expand the investigation to see the sources reviewed. If LanternIQ prepares a plan or strategic decision, review it before approval.

## 6. Start specialist work

Ask for a concrete deliverable, such as a content brief, competitor audit, FAQ, metadata set, presentation, research report, or content draft. LanternIQ starts the appropriate specialist when the required inputs are known.

Specialist work continues in the background and remains linked to the conversation, initiative, and resulting Project item.
