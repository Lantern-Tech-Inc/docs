---
title: "Beam"
description: "Apply bounded agent actions across structured rows of work."
---

Beam applies agent actions across structured rows. Use Beam when the same bounded task must run across many pages, keywords, records, or prompts.

## Create a grid

Start from a blank grid, a CSV file, a sitemap, or Google Search Console data.

## Add agent columns

Agent columns transform row inputs into durable outputs. Available actions include SERP research, content briefs, article drafts, page refreshes, meta titles, and brand-voice QA.

## Review usage before running

Each selected cell reserves one included agent run. Beam shows the selected cells and expected allowance before starting the batch.

## Batch limits

Your plan controls the maximum cells per batch. The platform supports grids up to 100 columns and 1,000 rows, subject to payload and plan limits.

## Failures and retries

Cells report their own status. Retry only the failed cells you want to run again. Manual retries consume additional runs.
