Projects is a library of every final output your agents have produced — articles, presentations, ad campaigns, SEO reports, research documents, and PR materials.

## Project types

| Type | Description |
|---|---|
| Article | Blog posts, landing pages, thought leadership |
| Presentation | Slide deck outlines and scripts |
| Ads | Google Ads campaign copy and structure |
| PR & Comms | Press releases, pitches, announcements |
| SEO Report | Full site audits and keyword reports |
| Research | Market, competitor, or topic research |

## Project statuses

| Status | Meaning |
|---|---|
| Draft | AI has produced output; not yet reviewed |
| Ready | Reviewed and ready to publish |
| Approved | Approved by a team member |
| Published | Live on your website or platform |
| Archived | Kept for reference but no longer active |

## Opening a project

Click any project row to open it. This takes you to the agent run that produced it, where you can read the full output, edit it in the rich-text editor, and publish it to your CMS.
