Prompt Analysis connects tracked buyer questions to the AI answers, brand mentions, competitors, and citations observed for each prompt.

## Prompt library

Organize prompts by topic and buyer intent. Use questions real buyers ask, not keyword fragments written only for scoring.

## Cohort changes

Changes to the tracked prompt cohort can affect trend comparability. Review proposed cohort changes before applying them and preserve the baseline used for later verification.

## Recommended coverage

Cover category discovery, use cases, comparisons, alternatives, risks, implementation, and direct brand questions. Avoid near-duplicate prompts that overweight one topic.
