title: "Agents overview"
description: "Run specialists for defined marketing deliverables and review their durable outputs."
---

Agents are reusable specialist workflows for defined marketing outcomes.

Each specialist has a bounded purpose, expected inputs, available evidence, and a durable output. LanternIQ can launch the right specialist from a clear request, or you can create and run an agent from the Agents workspace.

## Run an agent

1. Choose a specialist or existing agent.
2. Provide the required goal and inputs.
3. Review the expected run allowance.
4. Start the run.
5. Follow progress or continue working elsewhere.
6. Review the output in the run and Projects.

## Progress and results

Runs show meaningful stages, evidence work, specialist decisions, and the final output. Technical prompts, payloads, and hidden instructions are not part of the customer-facing record.

## Schedules

Reusable agents can run manually or on a configured schedule where scheduling is available. Confirm the goal, data access, output destination, and approval behavior before enabling recurring work.

## Publishing safety

Generating a draft is not the same as publishing. Live publication and other external actions depend on the connected system, workflow configuration, permissions, and approval boundary.
