## Why Meta Tags Matter for AI Search

Meta tags provide essential information about your pages to AI platforms. They help AI understand your content's purpose, context, and relevance when generating responses.

<Info>
  **Key Insight**: AI platforms often use meta descriptions and titles as primary sources for understanding page content before crawling the full page.
</Info>

## Essential Meta Tags

### 1. Title Tag

The most important meta tag for both SEO and AI search:

```html
<title>Lantern - AI Search Analytics Platform | Track ChatGPT & Perplexity</title>
```

**Best Practices:**
- ✅ 50-60 characters optimal
- ✅ Include primary keyword
- ✅ Brand name at end
- ✅ Unique for every page
- ✅ Descriptive and clear

**Examples:**

```html
<!-- Homepage -->
<title>Lantern - AI Search Analytics | Monitor Brand Mentions in ChatGPT</title>

<!-- Product Page -->
<title>AI Search Monitoring Tool - Track Brand Visibility | Lantern</title>

<!-- Blog Post -->
<title>How to Optimize Content for AI Search - Complete Guide | Lantern</title>

<!-- Documentation -->
<title>Structured Data Guide - AI Search Optimization | Lantern Docs</title>
```

### 2. Meta Description

Summarize your page content:

```html
<meta name="description" content="Track your brand visibility across ChatGPT, Perplexity, Gemini, and Claude. Real-time monitoring, attribution tracking, and content optimization for AI search.">
```

**Best Practices:**
- ✅ 150-160 characters optimal
- ✅ Include target keywords naturally
- ✅ Write compelling copy
- ✅ Include a call-to-action
- ✅ Accurately describe page content

**Examples:**

```html
<!-- Homepage -->
<meta name="description" content="Monitor your brand across AI platforms. Track mentions in ChatGPT, Perplexity, and Gemini. Get insights, attribution data, and optimize for AI search. Start free trial.">

<!-- Feature Page -->
<meta name="description" content="Discover which websites AI platforms cite when discussing your brand. Track citation sources, identify content gaps, and improve your AI search visibility with Lantern.">

<!-- Blog Post -->
<meta name="description" content="Learn how to optimize your website for AI search engines. Complete guide covering structured data, meta tags, content structure, and technical SEO for ChatGPT and Perplexity.">
```

### 3. Meta Keywords (Legacy)

Not recommended for modern SEO but can help some AI platforms:

```html
<meta name="keywords" content="ai search, chatgpt analytics, perplexity tracking, ai seo">
```

<Warning>
  Google ignores meta keywords, but some AI platforms may still reference them. Use sparingly and naturally.
</Warning>

### 4. Canonical URL

Tell AI which version of a page is authoritative:

```html
<link rel="canonical" href="https://asklantern.com/products/ai-analytics">
```

**When to use:**
- Multiple URLs for same content
- Paginated content
- Similar pages
- HTTP vs HTTPS
- www vs non-www

### 5. Robots Meta Tag

Control indexing and crawling:

```html
<!-- Allow indexing and following links (default) -->
<meta name="robots" content="index, follow">

<!-- Prevent indexing but follow links -->
<meta name="robots" content="noindex, follow">

<!-- Allow indexing but don't follow links -->
<meta name="robots" content="index, nofollow">
```

**AI-specific robots tags:**

```html
<!-- OpenAI (ChatGPT) -->
<meta name="gptbot" content="index, follow">

<!-- Google Extended (Gemini) -->
<meta name="google-extended" content="index, follow">
```

## Open Graph Tags

Optimize how your content appears when shared and cited:

```html
<!-- Basic Open Graph -->
<meta property="og:title" content="Lantern - AI Search Analytics Platform">
<meta property="og:description" content="Track your brand visibility across ChatGPT, Perplexity, Gemini, and Claude with real-time monitoring and attribution.">
<meta property="og:type" content="website">
<meta property="og:url" content="https://asklantern.com">
<meta property="og:image" content="https://asklantern.com/images/og-image.jpg">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:site_name" content="Lantern">
<meta property="og:locale" content="en_US">
```

## Twitter Card Tags

Optimize for Twitter/X sharing:

```html
<!-- Summary Card -->
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:site" content="@asklantern">
<meta name="twitter:creator" content="@asklantern">
<meta name="twitter:title" content="Lantern - AI Search Analytics Platform">
<meta name="twitter:description" content="Track your brand visibility across ChatGPT, Perplexity, Gemini, and Claude">
<meta name="twitter:image" content="https://asklantern.com/images/twitter-card.jpg">
<meta name="twitter:image:alt" content="Lantern AI Search Analytics Dashboard">
```

**Card Types:**

```html
<!-- Large Image Card -->
<meta name="twitter:card" content="summary_large_image">

<!-- Small Summary Card -->
<meta name="twitter:card" content="summary">

<!-- App Card -->
<meta name="twitter:card" content="app">

<!-- Player Card (for video/audio) -->
<meta name="twitter:card" content="player">
```

## Language and Regional Tags

Help AI understand your content's language and target region:

```html
<!-- Page Language -->
<html lang="en">

<!-- Alternate Language Versions -->
<link rel="alternate" hreflang="en" href="https://asklantern.com">
<link rel="alternate" hreflang="es" href="https://asklantern.com/es">
<link rel="alternate" hreflang="fr" href="https://asklantern.com/fr">
<link rel="alternate" hreflang="x-default" href="https://asklantern.com">

<!-- Content Language -->
<meta http-equiv="content-language" content="en-US">

<!-- Geographic Target -->
<meta name="geo.region" content="US">
<meta name="geo.placename" content="United States">
```

## Author and Publisher Tags

Establish content authority:

```html
<!-- Author Information -->
<meta name="author" content="Jane Smith">
<link rel="author" href="https://asklantern.com/authors/jane-smith">

<!-- Publisher Information -->
<link rel="publisher" href="https://asklantern.com">

<!-- Copyright -->
<meta name="copyright" content="© 2026 Lantern">
```

## Content Type Tags

Help AI understand your content format:

```html
<!-- Content Type -->
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8">

<!-- Article Type -->
<meta property="article:content_tier" content="free">

<!-- Reading Time -->
<meta name="reading_time" content="5 minutes">

<!-- Content Rating -->
<meta name="rating" content="general">
```

## Image Optimization for Meta Tags

<AccordionGroup>
  <Accordion icon="image" title="Image Dimensions">
    Use optimal sizes for different platforms:
    - **Open Graph**: 1200 x 630 px
    - **Twitter Large Card**: 1200 x 628 px (or 2:1 ratio)
    - **Twitter Summary**: 240 x 240 px minimum
    - **Favicon**: 32 x 32 px, 192 x 192 px, 512 x 512 px
  </Accordion>
  
  <Accordion icon="file" title="Image Format">
    Best formats:
    - **JPG**: Photos and complex images
    - **PNG**: Logos, text, transparency
    - **WebP**: Modern, smaller file size
    - **SVG**: Icons and logos (not for OG images)
  </Accordion>
  
  <Accordion icon="text" title="Alt Text">
    Always include descriptive alt text:
    
    ```html
    <meta name="twitter:image:alt" content="Lantern AI Search Analytics Dashboard showing real-time brand monitoring">
    ```
  </Accordion>
</AccordionGroup>

## Common Mistakes to Avoid

<CardGroup cols={2}>
  <Card title="Duplicate Tags" icon="copy">
    Don't use same title/description across pages
  </Card>
  
  <Card title="Too Long/Short" icon="ruler">
    Keep titles 50-60 chars, descriptions 150-160 chars
  </Card>
  
  <Card title="Missing Images" icon="image-slash">
    Always include OG and Twitter images
  </Card>
  
  <Card title="Wrong URLs" icon="link-slash">
    Use absolute URLs, not relative paths
  </Card>
  
  <Card title="No Canonical" icon="link-simple">
    Always specify canonical URL
  </Card>
  
  <Card title="Keyword Stuffing" icon="ban">
    Write naturally, don't over-optimize
  </Card>
</CardGroup>
